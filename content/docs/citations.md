# Citations

Every answer is sealed by the sources it came from — that's the whole point of the name.

## How it works

Each sentence that uses a source is marked with a numbered seal, like `[1]`. The seals link back to the exact page, URL, or PDF page number the sentence came from. A visitor can open any seal to see the original passage.

## Why it matters

Support answers that can't be traced back to a source are easy to get wrong. Sigilla's model is instructed to answer **only** from the retrieved chunks and to cite every sentence it uses — if it can't cite a source, it says it doesn't know rather than guessing. See [How answers work](/docs/answers) for the retrieval and fallback behavior behind this.

## Multiple sources

When an answer draws on more than one chunk, each sentence gets its own seal, and the widget lists every distinct source underneath the answer (for example "Sealed by 2 sources — Shipping Policy · FAQ").
