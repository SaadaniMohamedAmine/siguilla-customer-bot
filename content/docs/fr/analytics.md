# Analytics

La vue d'ensemble de chaque agent et la page Analytics présentent quatre chiffres, sur 7, 30 ou 90 jours :

- **Conversations** — nombre de conversations de visiteurs démarrées sur la période (les conversations du Playground sont toujours exclues).
- **Résolues sans humain** — la part de ces conversations qui n'ont jamais abouti à un passage à un humain.
- **Satisfaction** — pouces vers le haut divisés par (pouces vers le haut + pouces vers le bas) sur les réponses du bot.
- **Taux de repli** — réponses du bot qui ont décliné, divisées par toutes les réponses du bot.

Vous y trouverez aussi un graphique des conversations par jour, les sources les plus citées, vos questions les plus fréquentes, et les questions sans réponse qui méritent d'être couvertes par du nouveau contenu.
