# Personnaliser le widget

L'onglet Widget vous montre un aperçu en direct de chaque changement.

- **Couleur** — choisissez un préréglage ou n'importe quelle valeur hexadécimale. Le texte posé sur votre couleur bascule automatiquement entre encre claire et sombre pour garder le contraste.
- **Thème** — sombre ou clair.
- **Position** — en bas à droite ou en bas à gauche.
- **Style de l'en-tête** — discret ou marqué.
- **Avatar** — importez une image, ou gardez le monogramme par défaut.
- **Messages** — message d'accueil, texte du champ de saisie, jusqu'à 3 questions suggérées, et une infobulle facultative sur le lanceur.
- **Badge** — le badge « Sealed by Sigilla » peut être masqué avec les offres Pro et Team.

Les changements n'atteignent les visiteurs qu'une fois que vous cliquez sur **Publier les changements**.
