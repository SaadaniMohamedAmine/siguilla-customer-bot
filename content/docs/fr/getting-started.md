# Démarrer

Créez un compte avec votre e-mail ou Google/GitHub. Sigilla vous donne automatiquement une organisation personnelle — aucun formulaire de configuration.

## L'assistant

Créer votre premier agent prend trois étapes :

1. **Identité** — donnez un nom à votre agent, ajoutez une description facultative et des instructions (ton, périmètre, ce qu'il faut éviter).
2. **Sources** — importez un PDF, explorez votre site web ou connectez Notion. Vous pourrez ajouter d'autres sources plus tard depuis l'onglet Sources de l'agent.
3. **Widget et intégration** — copiez la ligne d'intégration, puis cliquez sur **Mettre en ligne**.

## Publication

Un agent ne répond aux visiteurs qu'une fois **en ligne**. Un agent en brouillon fonctionne quand même dans le Playground, ce qui vous permet de le tester avant de le publier.
