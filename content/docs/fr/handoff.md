# Passage à un humain

Parfois, un visiteur a besoin d'une personne, pas d'un agent.

## Déclencher un passage

- Le visiteur peut demander un humain directement depuis le widget.
- Sigilla le déclenche automatiquement après 2 réponses de repli consécutives dans la même conversation.

Dans les deux cas, le visiteur peut laisser une adresse e-mail pour que votre équipe le recontacte même s'il ferme l'onglet.

## Prendre la main

Les passages en attente apparaissent dans **Conversations**, avec un badge dans la barre latérale. Cliquez sur **Prendre la main** pour rejoindre la conversation — votre agent cesse de répondre automatiquement, et vos messages apparaissent dans le widget en quelques secondes.

## Résoudre

Cliquez sur **Résoudre** une fois la conversation traitée. Si le visiteur envoie un nouveau message ensuite, votre agent reprend automatiquement la suite.
