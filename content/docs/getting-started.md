# Getting started

Create an account with email or Google/GitHub. Sigilla gives you a personal organization automatically — no setup forms.

## The wizard

Creating your first agent takes three steps:

1. **Identity** — name your agent, add an optional description and instructions (tone, scope, what to avoid).
2. **Sources** — upload a PDF, crawl your website, or connect Notion. You can add more sources later from the agent's Sources tab.
3. **Widget & embed** — copy the one-line embed snippet, then click **Make it live**.

## Publishing

An agent only answers visitors once it's **live**. A draft agent still works in the Playground, so you can test it before publishing.
