Embed the widget

Deploy the Sigilla conversational concierge to your client storefront with a single asynchronous HTML script tag. No build steps, no bundle overhead, under 5 KB gzipped.

01 Quick embed snippet

CDN Target

Place this tag immediately prior to the closing </body> tag of your storefront template. It functions seamlessly across Shopify Liquid, Webflow, Next.js, and custom HTML architectures.

HTML theme.liquid 
<!-- Sigilla Concierge Embed -->
<script
  src="https://sigilla.app/widget/v1.js"
  data-bot="pk_9f2a07c1b48e"
  data-theme="dark"
  data-accent="#9E2F45"
  async>
</script>
bolt

Zero Client Latency

The widget script evaluates asynchronously in less than 14ms and will never block critical DOM rendering or First Contentful Paint (FCP). Edge-cached across 285 metropolitan POPs via Sigilla's Private Atelier Network.

02 Configuration Parameters

Dataset Attributes

Fine-tune the presence, tonal theme, and viewport anchor coordinates using dataset attributes directly on the script element:

Attribute Type Default Description
data-bot string required Your Maison public token issued in the Atelier Security Vault.
data-theme auto | dark | light auto Synchronizes with visitor OS preferences or forces plum-velvet dark mode.
data-accent hex string #9E2F45 Bordeaux or signature brand hex code applied to concierge badges.
data-position bottom-right | bottom-left bottom-right Viewport corner alignment relative to luxury cart badges.

03 Listening to Events

Client Dispatcher

Intercept VIP client transitions, request human intervention, or synchronize telemetry with your bespoke CRM through custom Window events:

JavaScript app-telemetry.js
ES6+ 
// Triggered when automated concierge orchestrates a human advisor handoff
window.addEventListener('sigilla:handoff', (event) => {
  const { clientId, highJewelleryInterest, sentimentScore } = event.detail;
  
  // Relay metadata to your private atelier dashboard
  console.log(`VIP Handoff requested for ${clientId} [Intent: ${highJewelleryInterest}]`);
  
  // Optional: Trigger internal VIP chime or concierge SMS
  triggerPrivateLoungeNotification({
    vipId: clientId,
    confidence: sentimentScore
  });
});
